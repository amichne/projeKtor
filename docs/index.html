01

Use

Run the contract boundary

Pin both the Action commit and the stable projeKtor release. The Action obtains the verified release itself; consumers do not install or invoke a local launcher.

workflow.ymlcodex projection
- name: Project agent tooling
  id: projection
  uses: {{ACTION_REPOSITORY}}@FULL_COMMIT_SHA
  with:
    source: .
    harness: codex
    version: v1.0.0

- name: Consume validated projection
  run: find "${{ steps.projection.outputs.projection-path }}" -type f
02

Check

Make the Action the check

A successful Action step proves the source contract, projection, and selected harness payload. Put it on pull requests; no separate CLI installation is part of the consumer workflow.

check-agent-tooling.ymlpull request gate
name: Check agent tooling
on: pull_request

permissions:
  contents: read

jobs:
  contract:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@FULL_COMMIT_SHA
      - uses: {{ACTION_REPOSITORY}}@FULL_COMMIT_SHA
        with:
          source: .
          harness: codex
          version: v1.0.0
03

Commit

Commit projected contents safely

Project into runner-temporary storage, replace the tracked destination, and commit only when the generated tree changed.

project-and-commit.ymlskip empty commits
permissions:
  contents: write

steps:
  - uses: actions/checkout@FULL_COMMIT_SHA
  - name: Project source
    id: projection
    uses: {{ACTION_REPOSITORY}}@FULL_COMMIT_SHA
    with:
      source: .
      harness: codex
      output: ${{ runner.temp }}/projection
      version: v1.0.0

  - name: Commit changed projection
    shell: bash
    run: |
      set -euo pipefail
      rm -rf generated/codex
      mkdir -p generated/codex
      cp -R "${{ steps.projection.outputs.projection-path }}/." generated/codex/
      git add generated/codex
      if git diff --cached --quiet; then
        exit 0
      fi
      git config user.name "github-actions[bot]"
      git config user.email "github-actions[bot]@users.noreply.github.com"
      git commit -m "chore: refresh projected agent tooling"
      git push
