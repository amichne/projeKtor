{{PROJECT_NAME}}

A composite GitHub Action that validates one provider-neutral agent-tooling source tree and projects it into Codex or GitHub Copilot layout.

Use Check Commit projections JSON Schema

Use the Action

Pin the Action commit and projector release in production. The output directory is created outside the checked-out source tree by default.

- name: Project agent tooling
  id: projection
  uses: OWNER/REPOSITORY@FULL_COMMIT_SHA
  with:
    source: .
    harness: codex
    version: vX.Y.Z

- name: Read the projection
  run: find "${{ steps.projection.outputs.projection-path }}" -type f

From this repository root, build the launcher, verify the restored schema contracts, and exercise the complete Action boundary.

./gradlew check installDevelopmentCli --no-daemon

Commit projected contents

Project into runner-temporary storage, replace the tracked destination, and commit only when the generated tree changed.

permissions:
  contents: write

steps:
  - uses: actions/checkout@FULL_COMMIT_SHA
  - name: Project source
    id: projection
    uses: OWNER/REPOSITORY@FULL_COMMIT_SHA
    with:
      source: .
      harness: codex
      output: ${{ runner.temp }}/projection
      version: vX.Y.Z

  - name: Commit changed projection
    shell: bash
    run: |
      set -euo pipefail
      rm -rf generated/codex
      mkdir -p generated/codex
      cp -R "${{ steps.projection.outputs.projection-path }}/." generated/codex/
      git add generated/codex
      if git diff --cached --quiet; then
        exit 0
      fi
      git config user.name "github-actions[bot]"
      git config user.email "github-actions[bot]@users.noreply.github.com"
      git commit -m "chore: refresh projected agent tooling"
      git push
